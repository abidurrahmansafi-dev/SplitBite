## 🚀 How to Build Your APK (3 Easy Ways)

### Method 1: Build in Android Studio (Recommended)
1. Download and extract this ZIP file.
2. Open **Android Studio** (Hedgehog, Iguana, or Koala).
3. Select **Open** and choose this extracted folder.
4. Wait for Gradle to sync automatically (~1-2 minutes).
5. Click **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. Android Studio will notify you: *"APK(s) generated successfully."* Click **locate** to get `app-debug.apk`!
7. Or plug in your Android phone via USB and click the green **▶ Run** button.

---

### Method 2: 1-Click Cloud Build with GitHub (No Android Studio Needed!)
1. Create a free repository on [GitHub.com](https://github.com).
2. Upload or push these files to the repository.
3. Go to the **Actions** tab in your GitHub repository.
4. Click **Run workflow** (or simply push a commit).
5. The cloud builder will compile your APK in ~60 seconds.
6. Download the finished `SplitBite-debug-apk` artifact directly to your phone!

---

### Method 3: Command Line Terminal
If you have the Android SDK installed:
```bash
# On Linux / macOS:
chmod +x gradlew
./gradlew assembleDebug

# On Windows:
gradlew.bat assembleDebug
```
The output APK will be generated at:
`app/build/outputs/apk/debug/app-debug.apk`
